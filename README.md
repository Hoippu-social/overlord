# 🧪 DEVELOPMENT BOT

Это тестовая версия бота для экспериментов и разработки.

## Запуск
```bash
.\start.bat
```

## Панель управления
http://localhost:3001

## База данных
`bot/prisma/development.db`

## ✅ Можно:
- Экспериментировать с кодом
- Тестировать новые функции
- Ломать что угодно - это тестовая среда!
- Перезапускать сколько угодно раз

## 🚀 Рабочий процесс
1. Редактируйте код в этой версии
2. Тестируйте через http://localhost:3001
3. Когда всё работает → копируйте изменения в **Release**

## Конфигурация
Файлы `.env`:
- `bot/.env` - Настройки бота
- `dashboard/.env` - Настройки панели управления (порт 3001)

Используйте **DEV** Discord токены и Client ID (отличные от Production)!
